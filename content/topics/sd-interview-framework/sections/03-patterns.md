# Patterns
- **Capacity estimation**: back-of-envelope calculations for QPS, storage, bandwidth.
- **API design**: define endpoints with request/response schemas.
- **Data model**: choose SQL vs NoSQL based on access patterns.
- **Scaling**: horizontal vs vertical; read replicas; sharding.
- **Caching**: CDN, application cache, database cache.
- **Message queues**: async processing for non-blocking operations.
- **Load balancing**: round-robin, consistent hashing, geographic routing.
