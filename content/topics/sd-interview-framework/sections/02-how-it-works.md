# How It Works
1. **Clarify requirements** (5 min): functional requirements (what does it do?), non-functional requirements (scale, latency, availability), constraints (budget, timeline).
2. **High-level design** (10-15 min): draw the main components, data flow, and APIs; start simple and add complexity.
3. **Deep-dive** (15-20 min): zoom into 1-2 specific areas; discuss data model, scaling, fault tolerance.
4. **Trade-offs** (5-10 min): discuss alternatives, bottlenecks, and improvements.

Key: talk through your reasoning; don't design in silence.
