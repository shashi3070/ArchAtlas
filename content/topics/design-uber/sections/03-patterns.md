# Patterns
- **Geohash indexing**: lat/long → geohash string; nearby search = prefix match.
- **Quadtree**: hierarchical spatial partitioning; dynamic resizing.
- **ETA pre-computation**: road network graph with travel time edges.
- **Surge pricing**: demand/supply ratio → price multiplier.
- **Trip state machine**: REQUESTED → MATCHED → IN_PROGRESS → COMPLETED.
- **Idempotent location updates**: deduplicate GPS pings.
