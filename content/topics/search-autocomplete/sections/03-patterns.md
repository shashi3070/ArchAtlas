# Patterns
- **Trie with frequency**: each node stores top-K children by frequency.
- **Snapshot + delta**: periodic trie snapshot + real-time frequency updates.
- **Personalization**: blend global popularity with user's search history.
- **Blacklisting**: filter inappropriate or harmful suggestions.
- **Multi-language**: separate trie per language/script.
- **Edge caching**: CDN caches trie responses for common prefixes.
