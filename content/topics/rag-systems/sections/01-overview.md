# Overview
RAG (Retrieval-Augmented Generation) combines information retrieval with LLM generation. At query time, relevant documents are retrieved from a knowledge base and injected into the LLM prompt, grounding the response in factual data.

RAG reduces hallucination, enables access to private/up-to-date data, and provides citations. It is the standard pattern for knowledge-base chatbots, enterprise AI assistants, and search-augmented generation.
