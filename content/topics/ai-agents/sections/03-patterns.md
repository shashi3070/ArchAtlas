# Patterns
- **ReAct**: interleaved reasoning and action; simple and effective.
- **Plan-and-execute**: generate a full plan first, then execute each step.
- **Reflection**: agent reviews its own output and corrects errors.
- **Multi-agent**: specialized agents collaborate (e.g., researcher + writer + reviewer).
- **Tool use**: function calling with JSON schema; structured output for tool parameters.
- **Memory**: short-term (conversation context) and long-term (vector store) memory.
