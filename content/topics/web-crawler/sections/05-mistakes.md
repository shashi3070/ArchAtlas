# Common Mistakes
- **Ignoring robots.txt**: legal and ethical violations; IP bans.
- **No politeness**: hammering a single domain causes DoS.
- **Crawl traps**: URL patterns like `/tag/1/tag/2/tag/3/...` waste resources.
- **No dedup**: same page crawled multiple times wastes bandwidth.
- **No content type detection**: attempting to crawl binary files (PDFs, images) as HTML.
